Ver formato admitido

El JSON puede ser un objeto con name y questions, o directamente un array. correct acepta índice (0–5), letra (A–F) o el texto exacto.

{
  "name": "Modals SOC",
  "description": "Can, must, should…",
  "category": "normal",
  "questions": [{
    "topic": "Modals",
    "question": "You ___ reset the password.",
    "options": ["should", "yesterday", "since", "evidence"],
    "correct": 0,
    "explanation": "Should expresa recomendación.",
    "translation": "Deberías restablecer la contraseña."
  }]
}

CSV: question, optionA, optionB, optionC, optionD, correct, topic, explanation, translation. En JSON también puedes usar category con los valores normal o natural; en ambos formatos puedes elegir el tipo antes de confirmar la importación.
